Secrets: one path in, and the agent isn't on it

Secret values live in a password manager. External Secrets Operator pulls one declared item per need. Nothing copied into git.

One path in, because a second path is a leak you haven't found yet

Secret values live in a password manager. External Secrets Operator pulls one declared item per need out of it through an in-cluster bridge, and syncs it into the namespace that needs it.

Nothing is copied into git, and there is no second path, because a second path is just a leak nobody has noticed yet.

Stakater Reloader

Restarts a workload when the secret it consumes changes. Without it the operator rewrites the Secret and a Helm-rendered Deployment never notices — the kind of bug that survives for months because nothing is wrong.
