Five controls, none load-bearing alone

Five independent controls. Any one being wrong leaves the other four standing.

Five controls, independent on purpose

They are independent on purpose. Any one of them being wrong has to leave the other four standing — a single gate that mostly works is one bug away from nothing, and five narrow ones are one bug away from four.

1. Read-only RBAC

ClusterRole with get/list/watch only. No secrets, no exec, no token minting. Widening it is a visible diff.

2. Merge gate

Branch protection: PR required, code owner review, stale approval dismissal, enforced for admins, linear history.

3. Kyverno identity policies

Two ClusterPolicies watching the agent's own identity — one enforces read-only, one refuses privileged calls.

4. Secrets via 1Password + ESO

One path in. Agent has no read path. GitHub App identity with short-lived tokens minted by sidecar.

5. Default-deny NetworkPolicy

Every namespace default-deny both directions. Exceptions are objects in git. Agent egress: DNS, API server, webhook, git.

In order from hardest to bypass to easiest to get wrong — which is the order they're worth reviewing in.
