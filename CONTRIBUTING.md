# This repository is public

Every change here is on the internet once it merges.

The public scan in `.github/workflows/check-public.yaml` rejects addresses, hostnames, domains, and email. This site's own domain is the exception. Product names are fine. Do not widen the pattern to make a check pass.

Screenshots are pixels. The scan cannot see them. Do not add one unless it has been read for names, URLs, and channel text.

Edit the HTML in this repository. Pages publishes `main`.
