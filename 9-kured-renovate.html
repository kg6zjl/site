Auto-updates: Kured and Renovate

Kured watches for the reboot-required sentinel, drains one node at a time, runs in a 03:30–05:30 UTC window. Renovate runs hourly, opens a PR for each version bump.

Kured (node reboots)

Kured watches for the reboot-required sentinel, drains one node at a time, and runs in a 03:30–05:30 UTC window.

A Discord webhook notifies when a node reboots (via the kured-notify secret). The alerting rules include KuredRebootRequiredStuck (24h) so a stuck node is visible. The kured window alerts are expected, not incidents — they are silenced during the window.

Config lives in home-cluster/kured/ (HelmRelease, kured-alerts.yaml for KuredRebootRequiredStuck).

Renovate (dependency updates)

Renovate runs hourly, opens a PR for each version bump. It automerges patch, digest, and pin bumps (via its own App bypass, not GitHub's platform auto-merge, which still wants a human review). Minor bumps wait for human approval on the dashboard.

Custom managers handle: runner-tools.tsv (CLI pins), beast-exporters.sh (node_exporter/nvidia_gpu_exporter), FluxInstance (distribution pin).

CI gates: Renovate CI must pass, kubeconform validates HelmRelease values. Minor bumps wait for explicit dashboard approval. Control-plane pieces (Flux, Longhorn, media charts) wait for me.
